# Обработка инвойсов → баланс

Приложение читает инвойсы поставщиков из папки поставки (`excel\<дата>\{co,ec,ke,t_common}`)
и добавляет суммы в файл «балансы актуальные» в столбец нужного поставщика:
одна строка на поставщика за поставку, «отгрузка» = формула `=инв1+инв2+...`.
**Оригинал баланса не изменяется** — создаётся копия `..._auto.xlsx`.

## Шаг 1. Обработать поставку

Двойной клик по **`Обработать баланс.bat`** (или в терминале: `python -m pyparser.phase2`).

Само найдёт свежую поставку и свежий баланс в `excel\`. Создаст рядом с балансом:
- `..._auto.xlsx` — копия баланса с дописанными суммами (то, что распозналось);
- `..._auto_report.csv` — что записано / пропущено / на проверку;
- `..._auto_очередь.xlsx` — **редактируемая очередь** нераспознанного.

Повторный запуск ничего не дублирует (уже записанное пропускается).

Указать вручную (если нужно):
`python -m pyparser.phase2 --folder "excel\07.02" --balance "excel\баланс.xlsx"`

## Шаг 2. Разобрать очередь (нераспознанное)

Откройте `..._очередь.xlsx`. Жёлтые ячейки — заполнить:
- **Поставщик (колонка баланса)** — точное имя столбца из баланса;
- **Дата** — `ГГГГ-ММ-ДД` (для фрахта — из документа);
- **Суммы** — число или `a+b+c` (для фрахта выберите Total Prepaid из подсказки-кандидатов);
- **Записывать** — поставьте `да`.

Затем двойной клик по **`Дописать очередь.bat`** (или `python -m pyparser.review`).
Создаст `..._ready.xlsx` — баланс с дописанными строками из очереди
(агрегируются по поставщику, дубли не пишутся).

## Что уходит в очередь
- новые поставщики без алиаса (добавьте столбец/алиас или впишите вручную);
- фрахтовые AWB-сканы (OCR даёт варианты суммы — выбираете Total Prepaid);
- документы без явного итога.

Манифесты и сводники (`*BXS*`, `GLOBAL-FFG, ...`, `Реализация`-манифесты) пропускаются автоматически.

## Добавить нового поставщика
Правьте `pyparser\aliases.py`:
- `FARM_ALIASES` — «фрагмент имени в инвойсе» → «имя столбца в балансе»;
- `NEW_COLUMNS` — если столбца ещё нет (создастся в конце листа).
